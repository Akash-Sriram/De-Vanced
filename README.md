# Google Photos Patches

A fork of [RookieEnough/De-Vanced](https://github.com/RookieEnough/De-Vanced) dedicated to Google Photos, containing custom fixes and future patch additions.

## Features

| Feature | Description |
|---|---|
| **MicroG Support** | Runs on non-root devices using MicroG / GmsCore for authentication. |
| **Account Avatar Bridge** | Loads your Google profile photo in the toolbar, account sheet, and switcher. |
| **Unlimited Backup** | Spoofs a Pixel device to enable unlimited original-quality backups and Pixel tools. |
| **Floating Pill Navigation** | Enables the modern bottom navigation bar (`Photos`, `Collections`, `Create`, `Search`). |
| **DCIM Backup Control** | Lets you selectively back up individual folders instead of forcing all of `DCIM`. |
| **Account Persistence** | Keeps your signed-in account active across app restarts. |
